# 中文化與分節導覽任務規格

專案：Karl Bushby「Goliath Expedition」（1998–2026，從智利蓬塔阿雷納斯徒步回英國赫爾）互動地圖。
使用者要求**嚴格考證**：所有內容只能取自 `research/` 的考證資料，不可加入資料中沒有的事實；不確定處要明說。
語言：**繁體中文（台灣用語）**。人名、地名第一次出現可附原文，例如「蓬塔阿雷納斯（Punta Arenas）」。

資料位置（專案根目錄 `D:\python\kaulBushby_goliathExpedition`）：
- `research/legNN.json`、`research/legNN.md`：各段考證（經過點、路段、停頓、來源與逐字引文、矛盾、未知）
- `data/route.json`：合併後的資料。**經過點 id 以這裡為準**（合併時刪除了 w02-001～w02-004、w04-001；w01-002、w02-013 的座標被判定不採用）
- `web/story.js`：現有 22 章的章節文字與時間窗（from/to）

---

## 工作一：經過點與停頓的中文簡述

輸出 `research/zh/legNN_zh.json`（UTF-8）：
```json
{
  "waypoints": {
    "w01-001": { "name": "智利蓬塔阿雷納斯", "summary": "1998 年 11 月 1 日官方出發地……" }
  },
  "pauses": {
    "p01-001": "休息、修理拖車輪軸"
  }
}
```
- 涵蓋該段 `data/route.json` 中**所有** leg 欄位為該段的經過點與停頓，一個都不能漏。
- `name`：地名的中文（譯名＋必要說明，例如「第 2 晚宿營點（日誌座標，經度可疑）」）。
- `summary`：1～3 句，忠實摘要該點的 `event`、日期（含精確度或區間）、座標依據的保留意見，以及來源引文中與此點直接相關的重點。不可推測或補充；英文資料沒說的就不寫。
- 停頓：把 `reason` 譯成簡潔中文（一句），保留不確定字眼。

## 工作二：導覽章節分「節」

輸出 `research/story/chNN.json`（NN 為兩位數章號，每章一個檔）：
```json
{
  "chapter": 5,
  "sections": [
    {
      "title": "離開麥德林",
      "from": "2001-01-14",
      "to": "2001-01-29",
      "text": "……可含 <b>粗體</b>；不確定處用 <span class=\"unk\">未知：……</span>",
      "wps": ["w01-134", "w01-140"]
    }
  ]
}
```
- 每章 3～6 節，依時間先後排列；每節的 from/to 必須落在章節時間窗內，前後銜接、不重疊（可有停頓期間的節）。
- 地圖會依每節的時間窗自動移動鏡頭並播放那段路線，所以時間窗要對應該節講的路段或停頓。
- 每節 2～4 句，比章節層級更細：具體日期、地點、事件、日誌中的細節（可轉述引文）。只能用考證資料中的事實。
- `wps`：1～4 個該節的關鍵經過點 id，必須存在於 `data/route.json`。
- 章節既有文字（web/story.js）是概述，分節不要逐字重複它，而是展開細節。
- 完成後自行驗證：JSON 可解析、所有 wps 存在、日期在章節窗內且遞增。
